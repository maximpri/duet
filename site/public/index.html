Duet pairs a frontier model with a local model. One writes the code. The other handles sensitive data. Duet checks what passes between them.

How Duet works ↓
01 / The approach

Two models.
One boundary.

01

Frontier models do the coding.

Plan changes, write code and fix failing tests using the code and context you permit.

02

Sensitive data is handled locally.

Files classified as sensitive are processed by your trusted local model. The frontier works from structure, synthetic examples and checked answers.

03

You can inspect the boundary.

Application checks, sandboxed tools and recorded outbound requests make the privacy controls visible.

Built for teams working with financial records, confidential systems and proprietary code.
